## 💡 CRITICAL LESSONS LEARNED

### Bug Prevention
1. **Orphan handlers cascade** - Single deleted element breaks everything
2. **Backup files are sacred** - Never auto-delete
3. **Multiple trigger points** - Game detection needs 3 paths
4. **Early initialization** - Call detectCurrentGame() at app startup
5. **API reliability** - Whisper better than Web Speech

### Development Best Practices
- Create backups before major refactors
- Run automated checks (bug-checker.js) before committing
- Test in realistic scenarios (Terraria gameplay)
- Document decisions in LEARNINGS.md
- Update documentation when adding features

### Architecture Decisions
- **Electron** over web app (OS integration)
- **Vanilla JS** over framework (small bundle)
- **PowerShell** for game detection (zero deps)
- **localStorage** for history (simple, private)
- **Collapsible UI** (gaming-friendly compact)

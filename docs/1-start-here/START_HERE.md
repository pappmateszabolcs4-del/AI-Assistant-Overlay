# Start Here

This folder is for a quick, self-contained onboarding. Use it when you need a fast orientation without jumping across documents.

## What You Get Here
- A concise project overview and status.
- Key development rules and safety constraints.
- A short release readiness checklist.

## How to Use It
- If you need a high-level status, read this file only.
- If you need technical depth, use the technical section of the docs folder.
- If you need release steps, use the reference section of the docs folder.

## Core Rules (Non-negotiable)
- Backups are sacred: never auto-delete them.
- User-facing text must be translated to all supported languages.
- Use custom modals; never use native dialogs.
- Run `npm run check` before commits.
